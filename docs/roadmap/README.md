# FGUI Agent Bridge 后续能力路线图

编写日期：2026-10-21。规划时基线：v0.13.0 / `99c9edc`。当前交付版本：**v0.19.0**，协议 `2.0`，116 个 MCP 工具，Editor 验证基线 6.1.4。

本目录保存各版本计划及其实施状态。**v0.14.0、v0.15.0、v0.16.0、v0.17.0、v0.18.0、v0.19.0 已实现并验收，其余计划待安排。** 每个版本有独立文档，可单独安排、实现和验收。未实施的版本号是建议的发布排序，实际实施时先核对已发布版本；若已有其他版本占用编号，应更新相关计划和依赖，不能覆盖既有标签。

## 优先级与版本清单

- P0：最直接减少常规 UI 制作中的手工/XML 操作，先补高频外观和对象结构能力。
- P1：补齐控件、布局、状态与实例编辑，形成较完整的组件编辑闭环。
- P2：涉及工程/包级影响或恢复机制，实施与验证成本较高，后续集中处理。
- 编号给出推荐实施顺序，不代表每个前序版本都是硬依赖；具体硬依赖见下表。无额外硬依赖的计划可按业务需要提前。

## 当前已完成能力与原生限制

v0.13.0 已实现分组高级模式、输入框提示、根遮罩、列表发布清空和组件实例资源替换，不应在后续版本重复建一套接口。基础几何、混合模式、根 opaque、列表项增删重排、同层 Relation、单文档 revision/回执与外部 XML 编辑交接也已存在。现有接口扩展必须保持这些语义。

v0.14.0 已实现 Graph 外观、Image 染色/透明度/翻转/填充及颜色滤镜六个工具。原生验证和范围限制见对应计划的实施结果。

v0.15.0 已实现按钮定义/实例设置和可识别六态资源的四个工具；作用域矩阵、空串与转换语义见[按钮编辑](../../.agents/skills/fgui-agent-bridge/references/button-settings.md)。

`GGroup.mainGridMinSize` 在当前 Editor 中没有可靠的组件 XML 持久化证据，本路线图不把它列作普通“加 setter 即可”的任务。若后续确有需求，先做独立宿主验证，再决定能否加入计划；不能仅凭内存赋值成功宣称完成。虚拟列表渲染、网络交互等游戏运行时代码不属于这些 Editor 能力计划。

## 公共接口与安全约定

1. 源码、MCP、CLI、能力协商、批量白名单和文档同步维护。新增字段同样需要能力标记，旧插件在入队前拒绝，包括批量内的同名 action 扩展字段。
2. 对象、文档、资源和实例覆盖的作用域必须明确。只改实例不能偷偷改共享组件；省略表示保持，清除/继承/空串/0 分别定义，禁止静默忽略未知字段。
3. 复用现有 `document_url + expected_revision + operation_key` 及回执机制，不把普通 setter 包装成完整事务；先验证输入和引用，再写入。
4. 默认保存行为沿用现有约定，明确是否保存整个文档、包或工程配置。保存成功、磁盘回读、重载回读、视觉、发布和 Unity/设备验证是不同证据。
5. 不覆盖用户未保存内容或并发修改，不因为已授权任务而机械增加逐项许可。涉及多个文档/文件时先生成可审查影响清单，在既有授权范围内执行。
6. 源 XML 可作为已授权任务的替代路径；若实现计划中的 API 尚未完成，不能用 XML 把接口验收标记完成。UI 任务因接口缺失转 XML 时，最终报告仍须列出具体能力缺口、修改范围、检查和重载情况。

## 每个计划的公共交付清单

- [ ] 核对当时源码、Editor 原生 API、字段作用域和 XML/设置文件真实持久化；草案不能直接当作已验证 API 合约。
- [ ] 修改 TypeScript 后编译并一并提交 `plugin/main.js`；同步 MCP/CLI、能力与旧插件拒绝规则、适用的批量白名单及技能/能力文档。
- [ ] 按变更补必要注释与 API 文档，复用现有机制；不可用扩大任意属性白名单代替专用引用和边界校验。
- [ ] 运行适当自动化检查，在隔离工程完成实际 Editor 保存、重载和所需视觉/发布验收；禁止向业务 UI 写入测试节点。
- [ ] 版本发布时核对插件、Python、锁文件、README、能力文档一致；协议若有不兼容变更需另行设计迁移，不能默认沿用 2.0。
- [ ] 实现与验收完成后提交 MCP 的实现、必要测试源码/可复用夹具及文档。测试日志、截图、临时工程、安装暂存和发布产物放仓库外，不入 Git。
- [ ] 是否发布标签及升级业务项目按实际任务授权执行；需要升级时分别核对固定 tag、安装包、插件快照、已加载插件和新 MCP 工具清单，不以 versionMatch 单项代替。
- [ ] 完成报告列出实现功能、相对路径/行号、实际验证证据、未验证项和已知限制，再更新本目录状态；禁止仅因代码提交而标记整项验收通过。
