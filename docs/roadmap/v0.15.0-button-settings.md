## 1. 目标与现状

让已有按钮的模式、选中内容、反馈效果和状态资源可以安全编辑，而不必重新创建按钮或手改 XML。

规划时证据：`src/fairygui_agent/mcp_server.py:225` 可在创建按钮时传模式与六态图；已有按钮只有父控制器绑定等接口。`replace_object_resource` 的 state 参数仍拒绝执行。

## 2. 本版本范围

- 按钮模式、选中标题/图标、标题颜色/字号、点击音效和音量、按压效果及参数。
- 区分按钮定义设置、父文档中可持久化的实例覆盖、仅预览状态。
- 对可明确识别的按钮状态资源提供读取与编辑；保留父控制器绑定和现有六态创建语义。

## 3. 接口草案

| 接口 | 输入、作用域与用途 |
|---|---|
| `fgui_get/set_button_settings` | target 或当前按钮定义；读取 scope、可写字段及设置 |
| `fgui_get/set_button_state_resources` | 在按钮定义文档中编辑 up/down/over/selectedOver/disabled/selectedDisabled 映射 |
| `fgui_get/set_button_binding（既有）` | 继续负责父控制器绑定，不承担共享定义改写 |

MCP 使用 snake_case，Bridge Action/参数沿用既有 camelCase 约定；最终签名以实施时确认的原生能力和兼容性为准。读取应返回足够的当前值、作用域与限制，使调用方能先读后写。

## 4. 关键语义与边界

- mode、默认音效等字段是否属于定义，必须由原生 Write/Write_editMode 与重载证明；实例接口不能悄悄改共享资源。
- 六态映射按稳定页面 ID、Gear 或原生可识别结构解析；不依靠子对象名称猜测复杂自定义按钮。
- 先覆盖 Bridge 自己创建的标准按钮及已验证映射；复杂或不唯一映射返回 unsupported_mapping，并列出候选和原因。
- 状态图必须是工程内图片 URL；省略保持，明确空串才清除，并核对空状态的原生回退语义。
- 模式切换可能影响父控制器/选中状态，执行前给出受影响项，保留 ID、布局、Gear 和 Relation。

## 8. 实施结果与验证边界

- 新增 get/set_button_settings、get/set_button_state_resources 四个 MCP 工具及 CLI；当前工具数 105，版本 0.15.0，协议仍为 2.0。旧插件在入队前拒绝，包括批量内的新 Action。
- 原生矩阵：mode、默认音效/音量、按压效果属于定义；title/selectedTitle/icon/selectedIcon 属于实例配置，定义内容编辑内部文本/Loader；标题颜色/字号两层可写。实例颜色、字号、音效必须启用原生覆盖标记。默认音量使用 Editor 百分数 0..100。
- 读取报告 scope、writableFields、实例覆盖、只读定义值与当前 displayedTitle；模式修改影响共享定义的全部实例，不重写父控制器绑定。实例 setter 可批量；定义和状态图不进入实例批量，不跨文档写资源。
- 六态通过稳定页面 ID 与 Display/Icon Gear 识别，不猜对象名称。复杂多候选、多重条件和缺失载体明确拒绝。Image 清空通过 Editor ReplaceSelection 转空 Loader，保持 ID/尺寸/Gear/Relation，并使用 scaleFree 保持恢复资源后的拉伸行为；返回转换清单。缺少页面保持原生回退，不自动创建。
- 类型/字段/颜色/范围/目标预检、空选中内容、静音、0 音量/按压参数、保存失败和无事务回滚均有自动化覆盖。110 项 Python 检查通过，其中新增执行 16 项编译按钮宿主契约。
- Editor 6.1.4 专用工程通过 35 项真实 MCP 检查：三种模式、原生写入/保存/重载、六态替换/清空/恢复、Icon Gear 默认回退、Bridge 创建的标准按钮、实例独立覆盖、父绑定保留、批量单次保存及原生 XML 发布。五张联系图实际检查普通/选中内容、六态、清除和恢复；空 Loader 编辑占位标记不当作发布内容。
