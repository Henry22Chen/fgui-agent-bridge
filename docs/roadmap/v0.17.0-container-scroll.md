## 1. 目标与现状

补齐内边距、滚动条引用和裁剪等布局配置，使常见滚动弹窗可以通过 Bridge 完整配置。

规划时证据：`plugin/main.ts:4170` 的 scroll settings 只开放 overflow、scroll、scrollBarDisplay、flags、pageMode 和 pageControllerName；mask 与 opaque 已存在。

## 2. 本版本范围

- 根容器：四边内边距、可持久化尺寸约束和点击测试源。
- ScrollPane：横/竖滚动条资源、滚动条边距、柔化裁剪、下拉头/尾资源等原生持久化字段。
- 保持现有分页、控制器、flags 和根遮罩接口兼容。

## 3. 接口草案

| 接口 | 输入、作用域与用途 |
|---|---|
| `fgui_get/set_container_settings` | 当前根组件；结构化 margin、尺寸约束和 hitTestSourceId |
| `fgui_get/set_scroll_settings（扩展）` | 根或原生 List；新增资源引用和布局字段 |
| `fgui_get/set_mask_settings（既有）` | 继续只负责遮罩引用和反向标志 |

MCP 使用 snake_case，Bridge Action/参数沿用既有 camelCase 约定；最终签名以实施时确认的原生能力和兼容性为准。读取应返回足够的当前值、作用域与限制，使调用方能先读后写。

## 4. 关键语义与边界

- 四边距用有名字段，避免数组顺序歧义；尺寸约束 min/max 的未设置值和 0 语义以原生序列化为准。
- 滚动条必须引用正确扩展类型的组件，头/尾为组件资源；空串明确解除引用，拒绝自身和无效类型。
- 点击测试源与根遮罩、opaque 分别处理，不能用修改 touchable 模拟命中区域。
- 设置不隐式切换 overflow/scroll 模式；不兼容字段组合在写前拒绝，或要求调用方明确给出模式。
- 只编辑当前根定义或原生 List；嵌套组件需要打开所属文档，不能改实例引用背后的共享定义。

## 8. 实施与验收记录（2026-10-21）

- 新增 get/set_container_settings 两个 MCP 工具及 CLI，扩展既有 get/set_scroll_settings；总数110，版本0.17.0，协议仍为2.0。批量接入根设置和点击源前序别名；新增 scroll_settings_extended 能力标记，旧插件在直接和批量扩展写入前拒绝。
- 原生验证 FMargin.Parse 顺序为 top,bottom,left,right，尺寸 restrictSize 为 minWidth,maxWidth,minHeight,maxHeight。接口使用有名四边距补丁，整数可负；尺寸限制和柔化边缘只接受非负整数，0清除/未设置。拒绝数字字符串、布尔和小数，避免 Puerts 静默截断。
- 根 hitTestSourceId 支持直属 Image/非空 Graph 和空串清除；与 mask、opaque 和对象 touchable 分别处理。min/max 按最终组合预检，使用原生属性更新并刷新视口，保存比对完整根 XML。
- 滚动扩展支持 scrollBarMargin、clipSoftness、hzScrollBarRes/vtScrollBarRes、headerRes/footerRes。资源只读预检：组件、ScrollBar 扩展及唯一直属 bar/grip，拒绝自引用、错误资源、方向/模式冲突；空串清除，省略保持，不改共享定义。
- 修复既有 pageControllerName 的原生作用域问题：引用父文档控制器，只能在直属 List 开启 scroll 时绑定；根非空绑定会触发原生空引用，现于写前明确拒绝。pageMode 修改保留其他 flags 位，新资源/边距/裁剪设置不覆盖已绑定 List 分页控制器。
- 原生非 scroll 模式不序列化 scrollBarDisplay/flags/pageMode；响应 inactiveScrollFields 明确提示，文档解释重载默认值。资源、边距和柔化字段独立保留，不承诺原生未序列化的内存值会持久化。
