## 1. 目标与现状

为已有 ProgressBar、Slider 和 ComboBox 提供明确的属性读写，覆盖编辑器面板上的常用配置。

规划时缺少三类专用设置；现已新增六个 MCP/CLI 工具并接入能力协商和实例批量写入，工具总数116，协议仍为2.0。

## 2. 本版本范围

- ProgressBar：最小值、最大值、当前值、反向、标题模式，以及原生支持的声音配置。
- Slider：范围、当前值、反向、标题模式、整数模式、点击改变值。
- ComboBox：选项清单、下拉组件资源、方向、可见项数、选择控制器和原生可持久化默认显示。

## 3. 已交付接口

| 接口 | 输入、作用域与用途 |
|---|---|
| `fgui_get/set_progress_settings` | 当前定义或直属实例，返回 scope 和可写字段 |
| `fgui_get/set_slider_settings` | 范围与交互配置，默认不保存 |
| `fgui_get/set_combo_settings` | 结构化选项最终清单及下拉引用；默认显示字段需验证 |

MCP 使用 snake_case，Bridge Action/参数沿用既有 camelCase 约定；字段和作用域已按原生持久化验证，getter 返回 scope/writableFields/readOnlySettings/preview/numericConstraints。读取应返回足够的当前值、作用域与限制，使调用方能先读后写。

## 4. 关键语义与边界

- 先核实字段属于组件定义还是实例覆盖；仅内存预览的 value/selectedIndex 不能冒充可持久化默认值。
- min/max/value 同一补丁必须先整体验证再按稳定顺序写入，避免原生提前 clamp 吞掉调用方意图。
- ComboBox 的原生字符串数组列顺序须实测后转换成有名字段；最终清单新增/删除/重排语义固定。
- 下拉资源必须是合法组件；选项图标、控制器和空字符串按字段语义验证，不隐式改共享资源。
- 范围越界、整数模式和默认选中项冲突在修改前拒绝；是否允许空选项必须明确。

## 8. 实施与验收记录（2026-10-21）

### 持久化矩阵

| 控件 | 当前共享定义 | 父文档直属实例 |
|---|---|---|
| ProgressBar | titleType、reverse | min/max/value、sound、volume |
| Slider | titleType、reverse、wholeNumbers、changeOnClick | min/max/value |
| ComboBox | dropdown | items、title/icon、visibleItemCount、direction、selectionController、sound/volume、clearOnPublish |

定义内的范围/选项是预览状态，getter 标记 instanceValuesPersisted=false，setter 拒绝把它们当定义配置。实例写入核对共享扩展快照不变；真实回读证明另一实例和共享源未被修改。

### 已确认的原生边界

- ProgressBar 范围和值为 Int32；ProgressBar/ComboBox 音量为整数百分数0..100。范围最终须满足 min < max 且 value 在范围内，整体预检后按 min/max/value 稳定顺序赋值。
- Slider 的原生字段虽然是 Single，Editor 6.1.4 会把小数写入 XML，但重载后退回默认值；探针已观察到 min=-1.5/max=10.5/value=4.2 保存后回读为0/100/0。本接口因此仅支持可可靠重载的整数配置，wholeNumbers=false 也不开放小数。未用 XML 替代接口实现。
- ComboBox 原生列序为 title/value/icon，协议提供有名字段最终清单，支持新增/删除/重排/清空。dropdown 只在定义保存，验证唯一直属 list 模板；图片、声音和组件引用分别检查类型。
- 未绑定控制器时 title/icon 可作为默认显示保存；selectedIndex 没有独立持久化字段，不承诺唯一选项身份。绑定父控制器时根据当前索引刷新标题/图标，显式冲突的 title/icon 拒绝；清空选项需先或同时解除绑定。
- 三个 setter 仅允许实例批量，定义须在对应文档显式编辑。新六个 Action 各有同名 capability，直接/批量调用旧插件均在入队前拒绝。沿用原有保存、revision、回执和失败不自动回滚约定。
