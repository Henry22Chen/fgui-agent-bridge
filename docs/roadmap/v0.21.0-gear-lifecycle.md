- 状态：已实现并验收，交付版本 v0.21.0。
- 优先级：P1。
- 编写日期：2026-10-21；能力基线为 v0.13.0 / `99c9edc` / Editor 6.1.4。
- 计划编号不是发布承诺；实施前核对当时源码、版本及原生 API，不据此直接修改安装或标签。
- 总览与公共约定：[路线图](README.md)。接口已按下文实施结果落地，具体格式见 Gear 生命周期参考。

## 1. 目标与现状

扩展 Gear 编辑覆盖，并能明确解除绑定、移除配置和编辑缓动，避免常用状态变化仍需 XML。

规划时证据：v0.13.0 的 Gear 只允许 display/text/icon/xy/size/color；百分比 XY 被拒绝，其他 Gear 只能读取原始 XML，缓动设置仅保留而不可编辑。

## 2. 本版本范围

- 原生外观 Gear（Alpha/旋转/灰化/交互）、动画 Gear、字号 Gear、Display2 等可验证类型。
- Gear 删除/解绑、百分比 XY 和缓动的启用、时长、延迟及曲线。
- 保持既有六类完整替换协议，新增结构化读取其余类型。

## 3. 接口

| 接口 | 输入、作用域与用途 |
|---|---|
| `fgui_get/set_gear（扩展）` | 新增类型、百分比位置与缓动配置；完整替换单个 Gear |
| `fgui_remove_gear` | 明确区分删除 Gear 配置和解除控制器绑定的效果 |
| `fgui_get_gears（扩展）` | 返回类型化值与可编辑能力，不仅返回未解释 XML |

MCP 使用 snake_case，Bridge Action/参数沿用既有 camelCase 约定；最终签名以实施时确认的原生能力和兼容性为准。读取应返回足够的当前值、作用域与限制，使调用方能先读后写。

## 4. 关键语义与边界

- 每类 Gear 的值类型、默认值和页面值独立定义；不把 look/animation 等塞进通用字符串。
- 旧 setter 的未提供缓动字段继续保留；新增删除操作必须说明清除范围和当前显示恢复规则。
- 百分比 XY 的坐标空间、绝对坐标与百分比切换规则需基于原生行为；不以整数舍入代替百分比支持。
- Gear 页面引用必须存在；Display2 的条件组合和动画的 playing/frame/timeScale 等字段仅开放已验证部分。
- 未知 Gear 在操作其他类型时原样保留，不能重写或丢弃；只读未知类型仍能安全诊断。

## 8. 实施结果（2026-10-23）

- 在 v0.20.0 上扩展既有 get/set_gear，新增 look、animation、font_size、display2，合计十类；新增 remove_gear。MCP 共123个工具，协议仍为2.0。MCP/CLI、能力协商、批量参数和文档同步更新，旧插件在直接/批量入队前拒绝新增选项。
- look 为 alpha/rotation/grayed/touchable；animation 仅开放已验证的 frame/playing（原生 gearAni），不开放 timeScale、动画名或皮肤覆盖。已有扩展动画配置仍可读取诊断且禁止窄字段覆盖。Display2 的 and/or 以原生实际显隐验证。
- 百分比 XY 使用整数 x/y 加比例 percentX/percentY，比例1对应父尺寸100%；父尺寸改变后的下次 Gear 应用按新尺寸计算。xy/size/look/color 可用 tween 补丁编辑 enabled/duration/delay/ease；省略保持，关闭也保留时长、延迟与曲线，自定义曲线只保留。比例/look 与时间按原生三位/四位小数精度校验，返回实际值，拒绝低于0.0001秒的时长。
- 原生仅清空 controller 会留下不可持久化的内存配置，故 remove_gear 明确同时删除配置与绑定；普通值保持当前显示，剩余显隐 Gear 重算可见性，不声称恢复源默认值。幂等删除、未知 Gear 保留及 v0.20.0 页面引用扫描/清理均已回归。
- 实测补正根组件 set_properties 保存校验：使用 Write_editMode 的定义快照，普通实例仍用 Write。另修复 Windows 原生响应文件短暂锁定：继续轮询同一响应，不重发写命令；读成功后的清理锁不再误报执行失败。
- 自动化：142项 unittest 通过，其中 Gear 编译插件宿主夹具28个场景；TypeScript 5.4.5 编译、uv锁文件校验与Skill校验通过。
- 真实 Editor 6.1.4：隔离工程经 MCP 完成类型切页、默认值、父尺寸百分比、非法参数写前拒绝、删除、批量保存、控制器引用清理、保存重载及原生发布。三状态截图另行观察；正式插件重启后回读高级配置。
- 原生运行预览：临时测试钩子仅装到固定ID的仓库外夹具，采样 TestView 运行副本确认 Linear 缓动延迟0.5秒、持续1.5秒、插值及终点，并读取显示对象实际MovieClip播放游标确认走帧；正式插件不开放该钩子，验收后恢复正式文件。未执行 Unity 游戏或设备联调。
- 可复用测试源码与夹具入库；测试工程、探针产物、日志、截图、安装暂存和发布包统一保留在业务 FGUI 工程 .agent/tmp/fgui-0.21.0/，不提交。本轮没有为弥补接口缺失而修改业务UI XML。
