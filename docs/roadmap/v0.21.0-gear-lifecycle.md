## 1. 目标与现状

扩展 Gear 编辑覆盖，并能明确解除绑定、移除配置和编辑缓动，避免常用状态变化仍需 XML。

当前证据：`plugin/main.ts:465` 的 Gear 只允许 display/text/icon/xy/size/color；百分比 XY 被拒绝，其他 Gear 只能读取原始 XML，缓动设置仅保留而不可编辑。

## 2. 本版本范围

- 原生外观 Gear（Alpha/旋转/灰化/交互）、动画 Gear、字号 Gear、Display2 等可验证类型。
- Gear 删除/解绑、百分比 XY 和缓动的启用、时长、延迟及曲线。
- 保持既有六类完整替换协议，新增结构化读取其余类型。

## 3. 接口草案

| 接口 | 输入、作用域与用途 |
|---|---|
| `fgui_get/set_gear（扩展）` | 新增类型、百分比位置与缓动配置；完整替换单个 Gear |
| `fgui_remove_gear` | 明确区分删除 Gear 配置和解除控制器绑定的效果 |
| `fgui_get_gears（扩展）` | 返回类型化值与可编辑能力，不仅返回未解释 XML |

MCP 使用 snake_case，Bridge Action/参数沿用既有 camelCase 约定；最终签名以实施时确认的原生能力和兼容性为准。读取应返回足够的当前值、作用域与限制，使调用方能先读后写。

## 4. 关键语义与边界

- 每类 Gear 的值类型、默认值和页面值独立定义；不把 look/animation 等塞进通用字符串。
- 旧 setter 的未提供缓动字段继续保留；新增删除操作必须说明清除范围和当前显示恢复规则。
- 百分比 XY 的坐标空间、绝对坐标与百分比切换规则需基于原生行为；不以整数舍入代替百分比支持。
- Gear 页面引用必须存在；Display2 的条件组合和动画的 playing/frame/timeScale 等字段仅开放已验证部分。
- 未知 Gear 在操作其他类型时原样保留，不能重写或丢弃；只读未知类型仍能安全诊断。
