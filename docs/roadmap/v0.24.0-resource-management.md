- 状态：待安排，尚未实现。
- 优先级：P2。
- 编写日期：2026-10-21；能力基线为 v0.13.0 / `99c9edc` / Editor 6.1.4。
- 计划编号不是发布承诺；实施前核对当时源码、版本及原生 API，不据此直接修改安装或标签。
- 总览与公共约定：[路线图](README.md)。本文件中的接口均为草案，不代表当前 MCP 已存在。

## 1. 目标与现状

提供包与资源的常规管理，并通过完整影响预览和已知引用修复防止资源搬迁、改名和删除破坏 UI。

当前证据：当前通用资源移动/重命名/删除未开放，只有 MovieClip 专用删除；导入和创建组件能按需建目录，但不是完整包/目录管理。

## 2. 本版本范围

- 新建包、目录管理、资源/目录重命名与移动；包重命名/删除须通过同一影响检查。
- 扩展只读引用索引：组件引用、列表默认/显式项、图标/Gear、Loader、字体、按钮、滚动条、遮罩关联资源及发布配置中的已知引用。
- 通用删除默认拒绝仍被引用的资源；明确允许的引用替换/清理以受限计划执行。

## 3. 接口草案

| 接口 | 输入、作用域与用途 |
|---|---|
| `fgui_create_package / fgui_create_folder` | 受控包和目录创建，明确冲突策略 |
| `fgui_plan_resource_changes` | rename/move/delete 等结构化操作，返回文件与引用影响 |
| `fgui_apply_resource_plan` | 绑定 project、快照及变更计划；执行后回读 package.xml 与引用 |
| `fgui_find_resource_references` | 复用/扩展 v0.20.0 只读索引，报告覆盖范围与未知引用 |

MCP 使用 snake_case，Bridge Action/参数沿用既有 camelCase 约定；最终签名以实施时确认的原生能力和兼容性为准。读取应返回足够的当前值、作用域与限制，使调用方能先读后写。

## 4. 关键语义与边界

- 移动尽可能保留资源 ID；跨包导致 URL 变化时显式列出旧/新映射并修复所有已知引用。
- 资源删除不是普通 document undo；没有完整引用覆盖或遇到未知引用格式时不能声称安全无引用。
- 名称改变可能影响生成类/资源名字符串；扫描范围限定 FairyGUI 已知格式，不承诺自动重写业务代码或任意字符串。
- 所有文件操作验证规范化路径位于指定项目和包范围内，拒绝路径逃逸、大小写碰撞和目标冲突。
- Editor 持有相关脏文档时拒绝覆盖；保留可恢复的本地备份并逐项报告文件状态，不使用 force 绕过引用安全。
- 操作计划是审查与防并发载体；在已授权任务内可自主预检执行，不额外制造逐文件人工确认流程。

## 6. 验证与验收

| 场景 | 必须证明的结果 |
|---|---|
| 同包改名/移动 | 资源 ID 保留，package.xml、文件路径及引用一致 |
| 跨包移动 | URL 映射完整，列表/Gear/Loader 等已知引用可回读 |
| 被引用资源删除 | 默认拒绝，显式清理仅覆盖计划声明范围 |
| 未知引用/脏文档/并发变化 | 不覆盖用户内容，不错误返回无引用 |
| 路径及冲突边界 | 目录逃逸、大小写碰撞、重复目标被拒绝 |
| 部分失败和重开发布 | 逐文件结果真实，可恢复备份保留，产物引用有效 |

- [ ] 上述场景的自动化/宿主契约检查通过，未知字段和越权目标不能静默接受。
- [ ] 已在专用隔离 Editor 工程执行实际原生写入、保存和重载回读；涉及视觉/发布的场景另给对应证据。
- [ ] 公共交付清单全部核对；对未验证或原生不支持的字段如实列出，不用手改 XML 掩盖工具尚未实现。
