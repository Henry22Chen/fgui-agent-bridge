## 1. 目标与现状

补齐制作底板、圆角遮罩、染色图标和填充进度图时最常遇到的外观属性，减少因简单样式字段缺失转用 XML。

当前证据：`plugin/main.ts:3272` 的通用白名单不含图形填充、图片翻转或滤镜；现有 `get/set_image_settings` 编辑的是包级九宫格，不是显示对象的外观。

## 2. 本版本范围

- Graph：类型、填充色、线条颜色/粗细、圆角；多边形和正多边形的可持久化参数。
- Image：染色、翻转、填充方式、原点、方向与比例。
- FObject 颜色滤镜：亮度、对比度、饱和度、色相及清除；混合模式继续复用既有通用属性。

## 3. 接口草案

| 接口 | 输入、作用域与用途 |
|---|---|
| `fgui_get/set_graph_settings` | target + settings；作用于当前文档直属 Graph |
| `fgui_get/set_image_display` | target + settings；作用于直属 Image，与包级 image_settings 分开 |
| `fgui_get/set_filter_settings` | target + settings；滤镜类型及结构化参数，显式清除 |

MCP 使用 snake_case，Bridge Action/参数沿用既有 camelCase 约定；最终签名以实施时确认的原生能力和兼容性为准。读取应返回足够的当前值、作用域与限制，使调用方能先读后写。

## 4. 关键语义与边界

- 颜色统一接受 #RRGGBB/#RRGGBBAA，透明度 0 必须有效；线宽/圆角不得为负，填充比例范围由原生 API 核实。
- 多边形坐标采用对象局部坐标；顶点数、有限值、类型切换时保留/清空哪些参数必须明确，非法计划在任何修改前拒绝。
- 省略字段保持原值，清除滤镜使用明确操作；不把空串、null、默认值混为同一含义。
- 切换图形类型后调用必要的原生刷新，并分别验证舞台对象、原生序列化、保存与重载；不仅比较 setter 返回值。
- 仅开放在 Editor 6.1.4 可验证、可持久化的滤镜；不在本版本承诺所有运行时 shader 或模糊特效。

| 场景 | 必须证明的结果 |
|---|---|
| 矩形/圆角/椭圆/多边形 | 字段保存重载一致，图形实际刷新，类型切换不遗留无效数据 |

| 批量与保存失败 | 单次保存可核对 XML，失败如实返回已发生修改 |
