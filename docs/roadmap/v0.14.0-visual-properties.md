## 1. 目标与现状

补齐制作底板、圆角遮罩、染色图标和填充进度图时最常遇到的外观属性，减少因简单样式字段缺失转用 XML。

规划时证据：v0.13.0 的 `plugin/main.ts:3272` 通用白名单不含图形填充、图片翻转或滤镜；现有 `get/set_image_settings` 编辑的是包级九宫格。本版本通过专用接口补齐显示对象外观。

## 2. 本版本范围

- Graph：类型、填充色、线条颜色/粗细、圆角；多边形和正多边形的可持久化参数。
- Image：染色、翻转、填充方式、原点、方向与比例。
- FObject 颜色滤镜：亮度、对比度、饱和度、色相及清除；混合模式继续复用既有通用属性。

## 3. 接口草案

| 接口 | 输入、作用域与用途 |
|---|---|
| `fgui_get/set_graph_settings` | target + settings；作用于当前文档直属 Graph |
| `fgui_get/set_image_display` | target + settings；作用于直属 Image，与包级 image_settings 分开 |
| `fgui_get/set_filter_settings` | target + settings；滤镜类型及结构化参数，显式清除 |

MCP 使用 snake_case，Bridge Action/参数沿用既有 camelCase 约定；最终签名以实施时确认的原生能力和兼容性为准。读取应返回足够的当前值、作用域与限制，使调用方能先读后写。

## 4. 关键语义与边界

- 颜色统一接受 #RRGGBB/#RRGGBBAA，透明度 0 必须有效；线宽/圆角不得为负，填充比例范围由原生 API 核实。
- 多边形坐标采用对象局部坐标；顶点数、有限值、类型切换时保留/清空哪些参数必须明确，非法计划在任何修改前拒绝。
- 省略字段保持原值，清除滤镜使用明确操作；不把空串、null、默认值混为同一含义。
- 切换图形类型后调用必要的原生刷新，并分别验证舞台对象、原生序列化、保存与重载；不仅比较 setter 返回值。
- 仅开放在 Editor 6.1.4 可验证、可持久化的滤镜；不在本版本承诺所有运行时 shader 或模糊特效。

## 8. 实施结果与验证边界

- 新增六个 MCP 工具及相应 CLI、能力标记；三个 setter 可进入现有批量执行。默认不保存，保存核对整个组件的原生序列化；无完整事务回滚。
- Graph 支持五种类型及当前类型的有效几何字段；圆角顺序为左上、右上、左下、右下；多边形顶点预检拒绝自交和退化。
- Image 使用 Editor 原生 0..100 填充比例。原生 XML 只保存染色 RGB，因此 RGBA 输入的 A 映射到对象 alpha，读取明确返回 RGB color 和独立 alpha；RGB 输入保留透明度。
- 颜色滤镜只开放原生可持久化的 color/none；四个参数为 -1..1，清除保持混合模式。组件实例只修改父文档覆盖，不修改共享定义。
- TypeScript 5.4.5 编译通过；104 项 Python 自动化检查通过，其中执行 21 项编译插件的模拟宿主契约。
- 专用 Editor 6.1.4 工程通过真实 stdio MCP 完成 48 项检查，涵盖保存、磁盘核对、重载、非法输入拒绝、实例隔离、三个 setter 批量保存及原生 XML 包发布；实际检查图形、图片翻转、线性/径向填充和灰度滤镜截图。像素文件、共享组件及包级九宫格保持不变。
- 圆角遮罩图形的轮廓刷新与根遮罩引用保存回读通过；编辑态截图不作为游戏运行时遮罩裁剪证据。未进行 Unity/设备运行验证；未开放模糊、任意 shader、根和逻辑 Group 滤镜。
- 可复用测试源为 tests/test_visual_settings.py、tests/visual_host_harness.cjs、tests/live_visual_validation.py 和 tests/fixtures/visual/。日志、截图、临时工程和发布产物位于仓库外，不入库。本轮未用 XML 写入替代新工具实现。
